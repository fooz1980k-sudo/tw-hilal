# هلال — عناصر المواسم والمناسبات

5 عناصر تحوّل متجرك لأجواء المناسبة بضغطة: رمضان، العيد، اليوم الوطني، يوم التأسيس، الجمعة البيضاء. بانر بزخارف متحركة، شريط إعلانات، عدّاد للمناسبة يتحول لتهنئة، بطاقة تهنئة بكود هدية تنتشر بالواتساب، وعروض المناسبة.

| العنصر | الاسم |
|---|---|
| `salla-hilal-hero` | هلال · بانر المناسبة |
| `salla-hilal-ticker` | هلال · شريط الإعلانات |
| `salla-hilal-countdown` | هلال · عدّاد المناسبة |
| `salla-hilal-greeting` | هلال · بطاقة تهنئة |
| `salla-hilal-offers` | هلال · عروض المناسبة |

```bash
pnpm install
pnpm run build   # dist/<component>.js
pnpm run dev
```
